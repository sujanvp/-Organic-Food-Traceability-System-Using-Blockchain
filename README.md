# 🌱 Organic Food Traceability System Using Blockchain

## Overview

The **Organic Food Traceability System Using Blockchain** is a secure and transparent web application that enables tracking of organic food products throughout the supply chain. By integrating blockchain technology, the system ensures that every stage of the product lifecycle—from farming to the consumer—is recorded in an immutable ledger, improving transparency, authenticity, and consumer trust.

The system allows farmers, distributors, retailers, and consumers to interact through a secure platform where product information cannot be altered once stored on the blockchain.

---

# Features

* Secure user authentication
* Farmer registration and product management
* Distributor management
* Retailer management
* Consumer product verification
* Blockchain-based transaction records
* QR Code generation for each product
* Product lifecycle tracking
* Tamper-proof data storage
* Transparent supply chain monitoring
* Dashboard for each stakeholder
* Search and filter products
* Real-time product status updates
* Responsive user interface

---

# Objectives

* Improve transparency in the organic food supply chain.
* Prevent counterfeit organic products.
* Ensure product authenticity.
* Enable consumers to verify product origin.
* Provide immutable records using blockchain.
* Increase trust between farmers, distributors, retailers, and consumers.
